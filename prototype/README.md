# WISLA FM — Prototype

Интерактивный UI-прототип (Vite + React + Tailwind v4). Mock-данные, без backend. Визуальный стиль — Monq.

## Запуск

```bash
cd prototype
npm install
npm run dev
```

Откройте URL из вывода Vite (обычно `http://localhost:5173`).

⚠️ Не используйте Live Preview и не открывайте `index.html` напрямую — Tailwind работает только через Vite.
